# Aset gratis KALA 0.10

Sumber diperiksa 27 Oktober 2026. Semua tambahan di bawah berdedikasi CC0 1.0 dan disimpan lokal.

| Aset | Pembuat / halaman sumber | Adaptasi |
|---|---|---|
| Bedroom and Living Room Furniture | [3DAssets.dev](https://3dassets.dev/packs/bedroom-and-living-room-furniture), sumber geometri menyatakan Muse Spark via T3 Code | Ranjang, meja, lemari, kursi, laci, lampu, karpet dan gorden. Posisi/skala disesuaikan, material kayu/kain ditambahkan. KHR_mesh_quantization dikonversi offline menjadi float32 agar kompatibel dengan Godot 4.7.2; node, normal, UV dan animasi dipertahankan. |
| Classic Nightstand 01 | Kirill Sannikov / Poly Haven, [unduhan GLB Innerscene](https://www.innerscene.com/tools/library/3d-parts/victorian-nightstand-28fb8e24) | Nakas kamar dengan tekstur PBR asli, disesuaikan ukuran. |
| Cartridge fuse 10 × 38 mm gG 16 A | [Innerscene](https://www.innerscene.com/tools/library/3d-parts/cartridge-fuse-10-x-38-mm-gg-16-a-32915eb2) | Sekering operator, diperbesar agar terbaca sebagai pickup, diposisikan mendatar di meja. |

[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). File lokal dan SHA-256 akhir tercatat di `vendor_manifest_0_10.json`. Unduhan asli untuk konversi tersimpan di `tools/downloads/revision10_originals`, tidak dibawa ke build game. Konverter: `tools/dequantize10.mjs`.

Keypad, bingkai jeruji, shader lantai/kayu/kain dan logika animasi tambahan dibuat untuk KALA. Referensi keypad hanya dipakai sebagai arahan bentuk dan susunan; tidak ada model atau tekstur game lain yang diambil dari gambar tersebut. Lisensi/atribusi aset versi terdahulu tetap berlaku.
